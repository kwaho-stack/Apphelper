# Apphelper

매 시간 지정한 분 범위 안의 랜덤 시점에 클릭 매크로를 실행하고, 핵심 동작의 성공 여부를
GitHub Pages 에서 확인하는 Windows 트레이 앱입니다. 이 프로그램에서는 "클릭"을 **crash** 라고 부릅니다.

- 대상: Windows 10/11, 단일 모니터 (듀얼 모니터·화면 배율 대응 없음)
- 구성: Python + PySide6, PyInstaller 단일 exe

## 용어

| 용어 | 정의 |
|---|---|
| crash | 지정 좌표를 1회 클릭. 끝나면 커서를 원래 위치로 되돌림 |
| 기본동작 | crash(x, y) 와 대기(ms) 단계로만 이루어진 재사용 블록 |
| 핵심 crash | 클릭 전후로 좌표 주변 N×N(기본 5×5) 평균 색상을 비교해 `변함!` / `안변함!` 을 기록 |
| 시간대 슬롯 | 0~23시. 슬롯마다 사용 여부, 실행 분 범위, 블록 순서를 가짐 |

## 사용법

1. `Apphelper.exe` 를 원하는 폴더에 두고 실행합니다. 처음 실행하면 편집 화면이 열립니다.
   이후에는 트레이 아이콘(더블클릭 또는 메뉴 → 편집 화면 열기)으로 엽니다.
2. 왼쪽 라이브러리에서 **기본동작**과 **핵심 crash** 를 만듭니다. "좌표 따기"를 누르면
   화면이 어두워지고, 클릭한 위치가 좌표로 들어갑니다 (Esc: 취소).
3. 라이브러리 항목을 오른쪽 시간대 줄로 끌어다 놓습니다.
   - 줄 안에서 끌어서 순서 변경, 우클릭으로 복제/복사/삭제 (Delete 키도 삭제)
   - 줄 오른쪽 `⋯` 또는 우클릭: 시간대 복사, 붙여넣기(덮어쓰기/뒤에 추가), 모두 지우기
   - 다른 시간대 줄로 블록을 끌면 복사됩니다.
4. 사용할 시간대에 체크하고 실행 분 범위(예: 10~40분)를 정합니다.
   변경 내용은 자동 저장됩니다.
5. 트레이 메뉴의 **실행/일시정지** 로 켜고 끕니다.

### 프로필

편집 화면 맨 위 **프로필** 에서 여러 세트를 저장하고 바꿔 쓸 수 있습니다.
프로필마다 기본동작, 핵심 crash, 24시간 스케줄을 따로 가지며, GitHub·로그 설정은 함께 씁니다.

- 새 프로필(빈 상태) / 복제(현재 내용 복사) / 이름 변경 / 삭제
- 실행되는 것은 **현재 선택된 프로필** 하나입니다. 트레이 메뉴 → 프로필 에서도 바꿀 수 있습니다.
- 이전 버전의 설정은 '기본' 프로필로 자동으로 옮겨집니다.

### 핵심 crash 확인하기

- 핵심 crash 편집 창의 **지금 테스트** 버튼: 현재 시간대 좌표로 실제 crash 를 한 번 하고,
  클릭 전/후 평균 색과 결과(변함!/안변함!)를 보여줍니다. 결과 페이지에는 올리지 않습니다.
- 마지막 실행 결과(실패 이유 포함)는 편집 화면 아래쪽과 트레이 아이콘 툴팁에 표시됩니다.
- 새 핵심 crash 의 기준 시간대는 만든 시각의 시간으로 정해집니다.

### 핵심 crash 좌표의 시간별 변동

`좌표 = 기준좌표 + (배치 시간 − 기준 시간) × (dx, dy)`

예: 기준 1시, 좌표 (100,100), dy=+30 → 2시 (100,130), 3시 (100,160), 0시 (100,70).
편집 화면과 핵심 crash 편집 창에 시간대별 좌표가 미리보기로 표시되고, 화면 밖이면 빨간색 ⚠ 로
경고합니다. 화면 밖 좌표는 실행하지 않고 그 시간을 `실패` 로 기록합니다.

### 스케줄 규칙

- 매 시간이 시작될 때 그 시간 슬롯의 분 범위 `[시작분:00, 끝분:59]` 에서 실행 시각(분, 초)을 새로 뽑습니다.
- 앱을 시간 중간에 켜거나 현재 시간 슬롯을 수정하면, 남은 범위 안에서 다시 뽑습니다.
- 일시정지 중에 실행 시각이 지나가면 그 시간은 건너뜁니다.
- 블록 실행 중 하나라도 실패하면(화면 밖 좌표, 삭제된 블록 등) 그 시간은 `실패` 입니다.

## 결과 페이지 (GitHub Pages)

1. 결과용 레포를 만듭니다 (비공개 레포는 GitHub 요금제에 따라 Pages 사용이 제한될 수 있음).
2. Fine-grained 토큰을 만들고 그 레포 하나에만 **Contents: Read and write** 권한을 줍니다.
3. 편집 화면 → **설정** 에 소유자, 레포 이름, 토큰을 입력하고 "결과 페이지 지금 갱신"을 누릅니다.
   처음 갱신하면 `gh-pages` 브랜치가 생깁니다.
4. 레포 Settings → Pages 에서 Source 를 **Deploy from a branch**, 브랜치를 `gh-pages` / `(root)` 로 지정합니다.

동작 방식:

- 앱은 시작할 때, 매 시간이 시작될 때, 슬롯을 실행한 뒤, 설정을 바꿨을 때 결과를 갱신합니다.
- 갱신할 때마다 `index.html`(이 레포의 `pages/index.html` 템플릿), `results.json`, `.nojekyll` 로
  **부모 없는 커밋(parents=[])** 을 새로 만들고 `gh-pages` ref 를 `force=true` 로 교체합니다.
  브랜치에는 항상 커밋 1개만 남고, main 과 이력이 섞이지 않습니다.
- 커밋 메시지·작성자는 고정값 `update` 입니다.
- `results.json` 은 날짜·시간·분·결과만 담고, 7일이 지난 날짜는 갱신할 때 지웁니다.

```json
{"days": {"2026-10-11": {
  "9":  {"r": "실패"},
  "14": {"r": "작동", "m": 23, "k": ["변함!"]},
  "15": {"r": "대기"}
}}}
```

페이지 표시: `14시 — 23분 작동 [변함!]`, 체크했지만 실행 전이면 `대기`, 실패 또는
지나간 시간인데 실행되지 않았으면 `실패`. 기본은 오늘이고 최근 7일까지 고를 수 있습니다.

## 기록 최소화

- 포터블: 설치 프로그램·레지스트리 없이 exe 옆 `data/config.json` 에 설정·동작·토큰을 모두 저장합니다.
- 토큰은 이 파일에만 저장되고, 코드나 레포에는 들어가지 않습니다 (`data/` 는 `.gitignore` 에 있음).
- 스크린샷은 파일로 저장하지 않고, 픽셀 값은 메모리에서만 비교합니다.
- 로컬 로그는 기본 OFF. 설정에서 디버그 로그를 켜면 `data/debug.log` 에 남습니다.
- 설정 → **전체 데이터 삭제**: `data/` 폴더(설정, 저장된 동작, 토큰, 디버그 로그)를 한 번에 지웁니다.
- 실행 중에는 트레이에만 상주하고 콘솔 창, 팝업, 알림을 띄우지 않습니다.

## 개발

```bash
pip install -r requirements-dev.txt
python -m pytest -q          # 단위 테스트 (Windows 전용 테스트는 다른 OS 에서 건너뜀)
python run_apphelper.py      # 소스로 실행 (Windows 가 아니면 실제로 클릭하지 않는 더미 백엔드)
```

### exe 빌드 (Windows)

```bat
build.bat
```

`dist\Apphelper.exe` 가 만들어집니다. GitHub Actions(`.github/workflows/build.yml`)도 push 할 때마다
Windows 에서 테스트 후 exe 를 빌드해 아티팩트로 올립니다.

## 구조

```
apphelper/
  core/crash.py      crash, N×N 평균 색상, 변화 판정, 핵심 crash
  core/scheduler.py  랜덤 실행 시각 선택, 시간대 슬롯 스케줄러
  core/model.py      데이터 모델, 앱 폴더 JSON 저장/전체 삭제
  core/runner.py     슬롯 블록 순서 실행
  core/results.py    결과 JSON (대기/작동/실패, 7일 보관)
  core/publisher.py  gh-pages orphan 커밋 덮어쓰기 (GitHub Git Data API)
  platform_win.py    Win32 마우스/화면 읽기 (ctypes)
  service.py         스케줄러·실행·결과·갱신 연결
  ui/                편집 화면(드래그 앤 드롭), 대화상자, 좌표 따기
  app.py             트레이 상주, 단일 인스턴스
pages/index.html     결과 페이지 템플릿
```
